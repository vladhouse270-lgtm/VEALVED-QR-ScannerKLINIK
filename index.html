🔗 Сопряжение с компьютером

На компьютере откройте основной сайт клиники → Касса → Сопрячь телефон. На компьютере появится QR-код.

После нажатия Android должен показать запрос «Разрешить камеру».

📷 Сканирование услуги

Наведите камеру на QR-код услуги из прайса.

🟢 Телефон подключён

Связь с сайтом клиники активна. Отсканированные услуги отправляются на компьютер.
